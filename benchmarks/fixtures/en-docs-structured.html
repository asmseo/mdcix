Acme Cloud Documentation

Overview

Acme Cloud is a managed platform for deploying container workloads with built-in observability and budget controls for AI agents.

Pricing

Starter plans begin at $29 per month. Pro plans are $99 per month and include SSO. Enterprise pricing is custom.

Integrations

Native integrations include Slack, GitHub, and Webhooks. MCP stdio is supported for local agents.

Security

All traffic uses TLS 1.2+. Private network fetches require explicit configuration. Blocked or interstitial pages are never treated as successful extractions.

API Reference

POST /v1/outline returns section identifiers. POST /v1/read-budget packs content within a token budget using BM25.
